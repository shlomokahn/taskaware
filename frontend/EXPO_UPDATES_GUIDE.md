# ?? Expo Updates - מנגנון עדכוני ה-OTA

## מה זה Expo Updates?

**OTA (Over-The-Air) Updates** משמעו: עדכן את האפליקציה **ללא הורדת APK חדש** מ-App Store!

זה אומר:
- ? עדכוני JavaScript מיידיים
- ? בלי צורך לעברור אלים דרך App Store
- ? המשתמשים יקבלו את העדכון בלחיצה אחת
- ? עובד גם עם native קוד (אם אתה משנה רק JS)

---

## ??? איך זה עובד

### **תהליך בתוך האפליקציה:**

1. **UpdateChecker** בודק לעדכוני Expo Updates + גרסה מהשרת שלך
2. אם יש עדכון, מופיע Modal
3. המשתמש לוחץ "Update Now"
4. ה-app מורידה את העדכון דרך EAS
5. **ריסטארט אוטומטי** ? האפליקציה טוענת את הגרסה החדשה

## ?? איך ליצור עדכון

### **Step 1: עשה שינויים בקוד שלך**

לדוגמה, שנה משהו ב-`LoginScreen.js`:

```javascript
<Text style={styles.loginBrand}>TaskAware v1.0.1</Text>
```

### **Step 2: בדוק שאתה ב-production branch**

```bash
cd frontend
git checkout main  # או production branch שלך
git pull
```

### **Step 3: פרסם עדכון דרך EAS**

```bash
eas update --branch main
```

**או בחר את ה-branch באופן אינטרוקטיבי:**

```bash
eas update
```

**פלט דוגמה:**
```
? Manifest for branch: main generated
? Uploading to EAS...
? Update published successfully!

ID: 12345abc
Branch: main
Message: (no message)
```

### **Step 4: (אופציונלי) שדרוג גרסה ב-app.json**

כל כשתעדכן את ה-native code (לא רק JS), שדרוג את הגרסה:

```json
{
  "version": "1.0.1"
}
```

ואז בנה APK חדש:

```bash
eas build --platform android --profile production
```

## ?? תרחישים שונים

### **תרחיש 1: עדכון JavaScript בלבד** ?
זה מה שאנחנו עושים כרגע!

```bash
# שנה קוד בחזית (login, screens, וכו')
# אל תשנה native modules

eas update --branch main
```

### **תרחיש 2: עדכון עם native code**
אם שנית package native או תלויות:

```bash
# בנה APK חדש
eas build --platform android --profile production

# ואז אופציונלי, פרסם גרסה
eas update --branch main
```

### **תרחיש 3: עדכון חובה (Mandatory)**

1. צור גרסה חדשה בדטאבייס:

```python
from api.models import AppVersion

AppVersion.objects.create(
    version='1.0.1',
    release_notes='Critical security update - required!',
    is_mandatory=True,
    download_url=None  # Expo Updates יטופל בכך
)
```

2. פרסם העדכון:

```bash
eas update --branch main
```

3. המשתמשים יראו Alert ולא יוכלו לדלג

- ? שינויים ב-permissions

## ?? Best Practices

1. **בדוק את קודך קודם** - בדוק לוקלי `expo start` לפני ש-publish
2. **כתוב הערות שחרור** - תן למשתמשים להבין מה השתנה
3. **דקדוק עדכונים** - אל תשלח כל דקה (בדקו כל 24 שעות)
4. **rollback אם צריך** - אתה יכול לחזור לעדכון קודם

## ?? טרובלשוטינג

**בעיה**: Updates לא מופיעים
- ? וודא שהקוד שונה בעדכון
- ? וודא שרצת `eas update`
- ? בדוק: `eas update:list --branch main`

**בעיה**: הקוד לא משתנה אחרי Update
- ? נסה clear cache: `expo start --clear`
- ? כופה Reset של אפליקציה

**בעיה**: Native code שדרוג נדרש
- ? בנה APK חדש: `eas build --platform android --profile production`
