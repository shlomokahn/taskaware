# Contributing

## Scope
These guidelines apply to all files in this repository.

## Documentation Standards
- Write all documentation in **English**.
- Keep documentation **concise** and task-focused.
- Prefer short sections and bullet points over long paragraphs.
- Avoid duplicate explanations across files.

## Pull Request Requirements
- Keep changes scoped and easy to review.
- For refactor-only work, state explicitly: "No functional change".
- Include a brief summary of what was cleaned or improved.

## Review Checklist
- [ ] Documentation is in English.
- [ ] Documentation is concise.
- [ ] No functional behavior was changed unless explicitly stated.
